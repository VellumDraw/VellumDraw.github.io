Manual

Using Vellum

Vellum is a diagram editor for publication figures. This page covers what you need to start: installing, drawing, getting figures into Word, and letting an AI assistant draw for you.

Install

  1. Download vellum-windows-x64.zip from the download section.
  2. Unzip it to a folder you keep, for example %LOCALAPPDATA%\Programs\Vellum.
  3. Run vellum.exe. Pin it to Start or the taskbar if you like.

Windows may warn that the program is from an unknown publisher, because it is not code-signed. Choose More info, then Run anyway.

Drawings are saved as .vlm files. Vellum also opens and saves .vsdx.

Your first figure

  1. Pick a page. With nothing selected, the Properties pane shows the page: choose a paper size such as A4 or Letter, or a journal figure width (85, 120 or 175 mm).
  2. Place shapes. Click a shape in the Shapes pane, then click or drag on the page. The Engineering group has soil layers, footings, piles, loads and the water table; the Process group has valves, pumps and instruments.
  3. Connect them. Press C and drag from one shape to another. The connector stays glued when you move either shape.
  4. Type labels. Select a shape and just start typing.
  5. Style it. The Properties pane sets fill, hatch, line, shadow and text; Arrange aligns, distributes and lays out flow charts automatically.

Drawing at scale

Set a drawing scale in the Page pane (for example 1:50 in m). The rulers, dimensions and Size & Position then read in metres, so a 2.0 m footing is typed as 2.0 m. The printed page stays in millimetres.

Soil layers are rectangles with a hatch: sand, clay, silt, gravel, rock, peat, concrete or made ground. Hatches are drawn as real lines, so they print and paste exactly.

Text and equations

Labels understand a small markup:

TypeShows
m^3m³
k_{sat}ksat
\sigma_v'σv′
$\Delta h$Δh
\it{in situ}in situ

Thai text is set in the document's Thai font (Sarabun by default).

Equations: Insert > Equation (Alt+=) opens the equation editor, with symbol palettes, templates, ready-made formulas by subject and the LaTeX source. Double-click an equation to edit it again.

Word and PowerPoint

  • Ctrl+C copies the selection (or, with nothing selected, the drawing) as a vector EMF. Paste it into Word or PowerPoint: it arrives at its true size and stays sharp at any zoom.
  • Turn on Editable in Office (Home > Clipboard) to paste editable Office shapes and equations instead.
  • Copy for Word (Ctrl+Shift+C) always copies one vector picture.
  • Charts copied from Origin, Excel or PowerPoint paste into Vellum and stay vector; right-click > Convert to shapes makes them editable.

AI drawing (MCP)

vellum-mcp.exe is a Model Context Protocol server. Every Vellum command is a tool, so an assistant can do anything the menus can. With the Vellum window open, the assistant draws in it and you watch; without a window it works in the background and saves or exports files.

Claude Code

claude mcp add vellum -- "%LOCALAPPDATA%\Programs\Vellum\vellum-mcp.exe"

Use the folder you unzipped Vellum into if it is not the one above.

Claude Desktop

Add this to %APPDATA%\Claude\claude_desktop_config.json, with your own user name and folder, then restart Claude Desktop:

{
  "mcpServers": {
    "vellum": {
      "command": "C:\\Users\\<you>\\AppData\\Local\\Programs\\Vellum\\vellum-mcp.exe",
      "args": []
    }
  }
}

Other MCP clients

Any client that runs a stdio MCP server works: point it at vellum-mcp.exe with no arguments.

CommandBehaviour
vellum-mcpDraw in the open Vellum window; if none is open, work in the background and move into a window as soon as one opens.
vellum-mcp --guiAlways draw in the window.
vellum-mcp --headlessNever touch a window: draw in memory, save and export files.

What to ask for

Describe the figure as you would to a colleague, and say where it goes:

“Draw a strip footing on 2 m of sand over soft clay with the water table at 1.5 m, at 1:50, and copy it for Word.”

“Summarise these lecture slides as a design flow chart on one A4 portrait page, with an illustration of the wall, and save it as a PDF.”

The assistant renders the page after drawing to check its own work. You can keep editing the result by hand, or ask for changes.

Troubleshooting

  • Windows blocks the program: right-click the zip, choose Properties, tick Unblock, then unzip again; or use More info > Run anyway.
  • The assistant draws but the window does not change: the MCP server talks to the window on 127.0.0.1:7676. Open Vellum before asking, and make sure no other program uses that port.
  • The figure looks blurry in Word: paste with Ctrl+V after Ctrl+C in Vellum (not a screenshot), so Word receives the vector EMF.
